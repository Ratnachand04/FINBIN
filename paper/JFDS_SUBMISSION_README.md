# JFDS submission package

Target journal: **The Journal of Finance and Data Science** (Research Article).

Use `crypto_direction_evaluation.tex` as the anonymized manuscript and
`jfds_title_page.tex` as the separate, non-anonymized title page. The journal
uses double-anonymized review, so do not merge the author page into the review
manuscript. Upload `highlights.txt` separately if Editorial Manager requests it.

Before submission:

1. Replace every all-caps placeholder in `jfds_title_page.tex` with the final
   author names, affiliations, postal address, email, ORCIDs, funding,
   contributions, acknowledgements, and conflicts statement.
2. Create an immutable GitHub release and preferably archive it with Zenodo.
   Put the release tag/DOI in the title page. Do not cite a moving `main` branch
   as the version of record.
3. Supply reviewers with an anonymized archive (or an anonymous OSF link) that
   contains the three CSV inputs, evaluation scripts, backtest engine, tests,
   environment file, and JSON outputs, without Git metadata or author names.
4. Run `python scripts/evaluate_walkforward.py` and confirm that the generated
   `docs/evaluation_results.json` has not changed. Run
   `python scripts/mutation_matrix.py` and `python scripts/null_test_backtest.py`.
5. Compile both TeX files in Overleaf with pdfLaTeX. Check every table/figure,
   reference, line break, and hyperlink in the resulting PDFs.
6. Generate the separate Elsevier declaration-of-interests document required by
   the submission system. Obtain every coauthor's approval before submission or
   optional SSRN posting.

Verified locally on 22 September 2026:

- walk-forward output regenerated byte-for-byte identically;
- 32 focused correctness and inference tests passed;
- mutation score: 8/8 (29 baseline mutation-suite tests passed);
- randomized null test passed with 60 seeds and 2,400 bars.

The default `python.exe` on the verification machine was an incomplete Python
3.14 installation. Verification used `py -3.12`. The pinned project environment
should be used for the release artifact.
